# Atlas — запись повторов

Фоновая запись последних N секунд экрана со звуком, как NVIDIA ShadowPlay или Medal, только без «сломанных повторов».

## Установка

1. Скачай `Atlas-vX.Y.Z-win-x64.zip` со страницы [Releases](../../releases).
2. Распакуй в любую папку, например `C:\Atlas`.
3. Запусти `Atlas.exe`. Ничего доустанавливать не нужно: .NET и FFmpeg уже внутри.

Atlas живёт в трее. Нужна Windows 10 2004+ или Windows 11. Лучше всего работает с NVIDIA (NVENC), но подходят и AMD, Intel, и кодирование на процессоре.

| Клавиши | Действие |
|---|---|
| **Alt+F10** | сохранить повтор (последние 60 с по умолчанию) |
| **Alt+F11** | короткий повтор (последние 15 с, длина настраивается) |
| **Alt+F9** | начать / остановить полную запись |
| **Alt+Shift+F10** | включить / выключить буфер |
| **Alt+X** | оверлей поверх игры: быстрые действия и последние клипы |

Клипы сохраняются в `Видео\Atlas\<Игра>\`. Во вкладке «Клипы» есть поиск, фильтры по игре, дате и типу, сортировка, превью с длительностью.
Правый клик по клипу → «Сжать для Discord»: клип пережимается до 10 МБ и сразу копируется — вставляй в Discord через Ctrl+V.

Правый клик → «Обрезать…» (или клавиша T) открывает редактор с плеером: воспроизведение, перемотка по таймлайну, покадровый шаг, маркеры начала и конца (I / O), повтор фрагмента. Фрагмент сохраняется новым клипом мгновенно, без перекодирования.

Клавиша F (или правый клик) добавляет клип в **избранное** — фильтр «★ Избранное» во вкладке «Клипы».

**Раздельные дорожки** (Настройки → Звук): в клипе будет 3 дорожки — «Все звуки» (её играют плееры и Discord), «Система» и «Микрофон» отдельно для монтажа.

В настройках «Нагрузка на видеокарту» задаёт режим работы NVENC: «Минимальная» (p2), «Сбалансированная» (p4, по умолчанию) или «Максимальное качество» (p6).
На RTX 2060 при 1440p60 переход с p5 на p4 почти не меняет картинку, но заметно разгружает кодировщик.

> Если эти клавиши заняты NVIDIA Overlay, Atlas всё равно их ловит, но сохранят обе программы.
> Выключи «Мгновенный повтор» в оверлее NVIDIA (Alt+Z) или переназначь клавиши в Atlas.

## Что нового в 2.3

- **Запись игр в эксклюзивном полноэкранном режиме — одной кнопкой.** Если захват игры постоянно прерывается, Atlas предложит «Исправить»: в драйвере NVIDIA для этой игры включается «Способ представления OpenGL/Vulkan → через DXGI», а в Windows — «оптимизация во весь экран». Саму игру Atlas не трогает (для античита ничего не меняется). После перезапуска игры она записывается. Отменить — Настройки → Поведение → «Исправленные игры».

## Что нового в 2.2

- **Приложение на отдельной дорожке вырезается из звука системы.** Добавил Discord в «Отдельные дорожки» — на дорожке «Система» его больше не слышно, только на дорожке «Discord». «Все звуки» остаётся полной. Windows умеет вырезать из системы одно приложение за раз — если в списке несколько, вырезается первое запущенное.
- Стилизованный поиск в клипах: лупа, крестик очистки, подсветка при фокусе.

## Что нового в 2.1

- **Новый интерфейс:** иконки в меню, живой статус внизу боковой панели, главная с крупным блоком статуса, кнопками «Сохранить» и «Последние 15 с», плитками (буфер, клипы за сегодня, свободное место, кодировщик).
- **Уведомление о сохранении с превью клипа.**
- **Отдельные дорожки приложений** (Настройки → Звук): добавь, например, Discord или Spotify — каждое пишется ещё и на свою дорожку для монтажа. Пока приложение не запущено, его дорожка просто тихая.
- **Исключаемое приложение выбирается из списка запущенных.**
- В оверлее у плиток больше нет тёмных уголков.

## Что нового в 2.0

- **Звук только игры** или **весь звук, кроме Discord** (Настройки → Звук → «Что записывать»). Голоса из Discord, музыка и браузер больше не попадают в клип. Работает на Windows 10 2004+ через системный захват звука отдельного процесса.
- **Atlas знает, во что ты играешь.** Игра — это приложение, развёрнутое на весь монитор. Клипы называются по ней, даже если ты нажал клавишу, переключившись в Discord.
- **Монитор «Автоматически»:** запись идёт с монитора, где запущена игра. Если игру перенесли на другой экран, Atlas переключается сам через 3 с.
- **Лимит места под клипы** (Настройки → Папки): при превышении самые старые клипы удаляются навсегда, избранное (★) не трогается. По умолчанию выключено.

## Почему повторы не ломаются

- **Буфер на диске из 2-секундных кусков MPEG-TS.** Если кодировщик упадёт, уже записанное остаётся,
  а недописанный кусок тоже спасается.
- **Сторож.** Если ffmpeg упал, завис (10 с без данных), сменилось разрешение или ПК вышел из сна,
  запись перезапускается за ~1 с. Клип склеивается из кусков до и после сбоя.
- **Сохранение без перекодирования.** Куски склеиваются в .mp4 за доли секунды. Atlas ждёт, пока допишется
  текущий кусок, поэтому момент нажатия клавиши тоже попадает в клип.
- **Звук привязан к системным часам.** Тишина не «съедает» время, поэтому звук не уезжает от картинки.
  При смене наушников или колонок Atlas переключается на новое устройство сам.
- **Захват прямо на видеокарте.** Desktop Duplication → NVENC без копирования кадров в память процессора.
  Кодировщик подбирается сам: NVENC → AMF → QuickSync → x264.
- **Ровные кадры.** ffmpeg сам не повышает точность системного таймера и снимает кадры с шагом 15.6 мс — отсюда «дёрганый» fps. Atlas включает ему таймер 1 мс, отключает энергосберегающий троттлинг Windows и поднимает приоритет на видеокарте (как OBS).
- ffmpeg работает в Job Object и закрывается вместе с Atlas, даже если Atlas упадёт.

## Сборка

```bash
dotnet publish -c Release -o publish
```

Нужен .NET 10 SDK. FFmpeg в репозиторий не входит: скачай сборку [BtbN](https://github.com/BtbN/FFmpeg-Builds/releases)
(`ffmpeg-n8.1-latest-win64-gpl-8.1.zip`) и положи `ffmpeg.exe` и `LICENSE.txt` в папку `ffmpeg\` — при сборке они копируются рядом с `Atlas.exe`.

## Лицензия

Код Atlas — MIT (см. [LICENSE](LICENSE)). FFmpeg внутри релиза — отдельная программа под GPL v3.
Логи лежат в `%LOCALAPPDATA%\Atlas\Logs`, настройки — в `%APPDATA%\Atlas\settings.json`.

Проверка без интерфейса: `Atlas.exe --selftest 25 out.mp4` пишет 25 с, сохраняет повтор и создаёт отчёт `out.mp4.txt`.
